# Happy Construction
A static website for Happy Construction, a commercial general contractor.
Deployed to Cloudflare Pages.
https://www.happyconstructionar.com

## Development

- `make serve` — Local dev server at http://localhost:8000
- Pushing to `main` deploys automatically via Cloudflare Pages

## Status

Scaffold. The Cloudflare Pages plumbing, shared chrome, and design-token system
are in place; page copy, photography, and the brand palette are placeholders
pending client direction. See the "Placeholders" section of `CLAUDE.md` for the
find-and-replace list.
