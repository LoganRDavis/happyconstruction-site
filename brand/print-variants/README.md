# Print / garment variants

Colour-separation variants of the mark, for physical output — screen print,
embroidery, signage. **Nothing in this repo consumes them** and
`build-site-assets.py` does not read this directory; they are versioned here
only because this is the last surviving copy.

| File | Separation |
| --- | --- |
| `happy-construction-mark-1color-black.svg` | single-colour knockout, black |
| `happy-construction-mark-1color-yellow.svg` | single-colour knockout, brand gold |
| `happy-construction-mark-2color.svg` | two-colour |
| `happy-construction-mark-3color.svg` | three-colour |
| `happy-construction-mark-3color-yellow-garment.svg` | three-colour, trapped for a gold garment |
| `happy-construction-mark-4color.svg` | full four-colour |

## Provenance

These came from the same `happy-construction-brand/` kit described in
`../README.md` > Provenance, which renders a `print/` set from the masters. That
kit is **not on this machine** — checked 2026-09-24 — so unlike the masters in
the parent directory these cannot currently be regenerated. They sat loose in
`~/GitHub/` until they were moved here.

If the kit resurfaces, prefer regenerating from it and treat these as a
historical snapshot.
